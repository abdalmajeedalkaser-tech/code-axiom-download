About Code Axiom

Code Axiom is an educational programming assessment project designed to help users discover their programming skill level.

The project provides programming tests in different languages and levels. Users answer questions and solve programming problems, then receive a result that represents their current level.

Code Axiom focuses on assessment and learning, helping programmers understand their strengths and identify areas that they can improve.

Our goal is to make programming assessment simple, clear, and accessible for everyone who wants to understand their programming abilities and continue developing their skills.

Privacy Policy — Code Axiom

Last updated: September 7, 2026

Code Axiom respects your privacy. This Privacy Policy explains what information may be stored when you use the application.

1. Information We Store

Code Axiom may store:

  • Your name.
  • Your answers to programming tests.
  • Your test results and scores.
  • Your programming level.
  • Your completed tests and progress.

2. Information We Do Not Store

Code Axiom does not require or store:

  • Passwords.
  • Phone numbers.
  • Home addresses.
  • Payment information.

3. How We Use Your Information

The information stored by Code Axiom is used to:

  • Display your name in the application.
  • Calculate and display your test results.
  • Save your progress.
  • Show your programming level.
  • Improve your experience with the application.

4. Data Security

We take reasonable steps to protect the information stored by the application. However, no digital system can guarantee complete security.

5. Children's Privacy

Code Axiom is an educational application. We do not intentionally collect unnecessary personal information from children.

6. Changes to This Privacy Policy

This Privacy Policy may be updated when necessary. Any changes will be reflected in the application.

7. Contact

If you have questions about this Privacy Policy or Code Axiom, please contact the Code Axiom team.

Thank you for using Code Axiom.
